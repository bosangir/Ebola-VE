Ebola Vaccine Effectiveness, Bulape

A reproducible R pipeline for a test-negative study of Ervebo (rVSV-ZEBOV) effectiveness against laboratory-confirmed Ebola virus disease, Democratic Republic of the Congo.

R 4.6.x Status: preliminary Participant data not included

Overview

This repository holds the code that turns linked outbreak data into a clean analysis dataset, the vaccine-effectiveness estimates, and the figures and reports. It contains no participant data. You supply your own linked files locally, and the pipeline builds everything from them.

The design is a test-negative case-control study. Among suspected patients tested by RT-PCR, cases test positive and controls test negative, and the two groups are compared on prior vaccination. Vaccine effectiveness is VE = (1 - odds ratio) x 100.

Quick start

Install R 4.6.x and the required packages, put your linked files in the local data/ folder, then run:

Rscript run_all.R

On Windows you can double-click run_all.bat instead. Outputs are written to outputs/, which is never committed.

Pipeline

StepScriptProduces
0R/00_config.Rpackages, paths, shared helpers, coding maps
1R/01_import_validate.Rreads the linkage and laboratory files, checks the schema
2R/02_build_cohort.Rone row per participant, coded dataset, data dictionary, study flow
3R/03_analysis.RVE models, sensitivity analyses, mortality, figures, results bundle
4R/04_report.Rnarrative Word report, built from the bundle
5R/05_slides.RPowerPoint deck, built from the bundle

Every result lives in the saved bundle, so the report and slides hold no hand-typed numbers.

Data handling and privacy

Participant data stays on your machine. The data/ drop folder and all generated outputs, reports, decks and logs are listed in .gitignore and are never pushed. Only the code, the README, the example configuration and the shareable data dictionary are tracked. To read files from outside data/, copy config.local.R.example to config.local.R and set the paths there.

Requirements

install.packages(c("dplyr", "ggplot2", "writexl", "officer", "flextable", "jsonlite"))

officer and flextable are needed for the report and slides. jsonlite is optional, used only when a dashboard cleaning folder is supplied.

Methods in brief

The outcome is the episode-defining RT-PCR result, the first definitive specimen on or after symptom onset. The exposure is vaccinated against not vaccinated, with unknown status excluded and never imputed. Models are logistic regression, crude and adjusted, with Firth penalised regression where the data are sparse. Sensitivity analyses cover the exclusion of lower-confidence links, alternative outcome definitions, and the protocol window that counts a person as effectively vaccinated only more than 10 days before onset. A retrospective cohort estimates effectiveness against death among confirmed cases.

Preliminary and for internal review. All estimates are provisional.
